⚠️ Грабли тестов (НЕ баги продукта):
- PowerShell `ConvertTo-Json` разворачивает одноэлементный массив → сервер
  получает объект вместо массива (422/тихий отказ). Слать явную JSON-строку.
- Кириллицу в теле слать UTF-8-байтами (`[Text.Encoding]::UTF8.GetBytes`).
- Поле настроек бэкапа — `dailyAt` (camelCase), не `time`.
- LWW-проверки: «старый» timestamp должен быть старше УЖЕ ЗАПИСАННОГО, а не
  просто `now - N` (время между шагами теста уходит вперёд).
