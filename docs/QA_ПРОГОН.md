## Дополнение 2026-07-09 (2): принудительная смена пароля, rate-limit, отзыв JWT — 13/13 PASS

Изолированный сервер порт 9762 (debug exe, scratch-БД), скрипт auth-e2e:

- **Принудительная смена пароля**: встроенный `admin/admin` логинится с
  `mustChangePassword=true`; после смены пароля флаг снят. Пользователь,
  созданный админом, — флаг `true`; после сброса пароля админом — снова `true`.
  Самостоятельная регистрация флаг НЕ ставит.
- **Отзыв JWT (token_gen)**: смена своего пароля → СТАРЫЙ токен 401, эндпоинт
  вернул свежий токен (клиент не разлогинивается); сброс пароля админом →
  токен цели 401; блокировка → токен 401. Старые токены без claim `gen`
  считаются gen=0 и живут до первого bump.
- **Rate-limit /api/login**: 5 неудач подряд → **429** «Слишком много попыток
  входа. Подождите 30 секунд.» — даже с ВЕРНЫМ паролем; через 31с вход
  проходит. Ключ — логин (lowercase), успех сбрасывает счётчик.
- UI: экран «Смените пароль» (ServerScreen) перекрывает работу до смены,
  выйти можно.

Провайдер lmstudio уже в коде (OpenAI-совместимый `/v1/chat/completions`,
`/v1/models`, авто-выбор первой модели). Ollama (`:11434`) — запасной путь,
на этой машине не запущен (проверять при наличии).

**PDF fixed-layout (свайп/зум/панорамирование)** — модерновый Chromium
(Edge/WebView2-класс, web-сборка сервера):
- Рендер PDF (mupdf/pdf.js) — страница «PAGE 1» видна, индикатор 1/6.
- Листание (стрелка / `view.next()`) 1/6 → 2/6.
- Зум ползунком 100% → 250%/300% (атрибут `zoom-factor` на foliate-renderer,
  кламп 0.5–4).
- Панорамирование при зуме>1: появляются обе полосы прокрутки, wheel-скролл
  сдвигает видимую область (угол рамки → центр текста). Без ошибок консоли.

**Сканер «книга из фото» — OCR end-to-end** (модерновый Edge, OPFS есть):
загрузка фото страницы с русским текстом → формат EPUB (OCR) → сборка →
книга открылась, распознанный текст **посимвольно совпал** с оригиналом
(6 строк про осень). CBZ/EPUB/Searchable PDF-форматы в UI присутствуют,
авто-обрезка по краям листа.

**Эмулятор (AVD gg1, WebView 91) — ограничения старого движка:**
- FB2 (reflowable) — открывается и листается, ок.
- **PDF/CBZ не рендерятся**: pdf.js требует Chrome 94+ (static-блоки) и 98+
  (`structuredClone` = undefined в 91) → `SyntaxError` при загрузке. Не баг
  приложения — старый системный WebView эмулятора. Реальные телефоны = WebView
  100+.
- **Сканер недоступен**: нет OPFS (Origin Private File System, Chrome 102+).
  Приложение корректно гейтит с сообщением «браузер не поддерживает локальное
  файловое хранилище (OPFS)».
- Имя сервера в сетевой библиотеке — «Школьная библиотека» (проверено на
  Android). Скачивание книг с сервера, локальный автотег («Художественная»
  для FB2) — работают.

⚠️ **Мелкая грабля (не блокер):** при уходе с открытого fixed-layout PDF
foliate роняет в консоль `TypeError: ... reading 'documentElement'` в
`pdf.js onZoom` (observer зума срабатывает после размонтирования iframe-doc).
Не влияет на работу; кандидат на аккуратный teardown observer.
