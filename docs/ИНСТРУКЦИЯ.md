# Читалка для школьников — инструкция по использованию

Офлайн-первая читалка электронных книг для школы: приложение на телефоне /
компьютере + библиотечный сервер в локальной сети класса или школы. Интернет
не нужен — всё работает в школьной Wi-Fi-сети, данные не покидают школу.

Эта инструкция — для тех, кто пользуется системой: администратора,
учителя, ученика. Техническая документация — в `apps/server/README.md`
(API сервера) и `README.md` (устройство проекта).

---

## 1. Установка

### Телефон/планшет (Android)
1. Взять файл `Читалка-android.apk` (из папки `dist` или скачать со страницы
   сервера — см. «Обновления» ниже).
2. Открыть файл на устройстве и разрешить установку из неизвестных источников,
   если Android спросит.
3. После установки приложение работает и без сервера: книги можно открывать
   с устройства.

### Компьютер (Windows)
1. Запустить `Читалка-desktop-setup.exe`, пройти установщик.
2. Десктоп-версия умеет также **запускать библиотечный сервер** прямо из
   приложения (для маленького класса отдельный сервер не обязателен).
   Перед запуском приложение ищет серверы в сети: если сервер уже работает,
   покажет «В сети уже есть запущенный сервер: имя (адрес)» — дополнительный
   сервер в этом случае может запустить только вошедший администратор.

### Библиотечный сервер (компьютер учителя или школьный ПК)
1. Скопировать папку `server` (из `dist`) на компьютер, который будет
   «библиотекой». Внутри: `chitalka-server.exe`, папка `web` (интерфейс),
   `chitalka.db` (база), `library` (книги).
2. Запустить `chitalka-server.exe`. В окне появятся адреса вида
   `http://192.168.x.x:9700` — этот адрес вводят на устройствах.
3. Сервер должен быть в той же Wi-Fi/локальной сети, что и устройства
   учеников. При первом запуске брандмауэр Windows спросит разрешение —
   разрешить доступ в частной сети.
4. Остановить сервер — просто закрыть окно (порт освобождается корректно).

> Книги можно класть файлами прямо в папку `library` — сервер сам находит их
> раз в 15 секунд. Либо загружать через веб-интерфейс (см. ниже).

## 2. Первый запуск сервера (администратор)

1. Открыть в браузере адрес сервера (например `http://192.168.1.10:9700`) —
   откроется та же читалка с экраном входа.
2. Войти со встроенной учёткой: логин `admin`, пароль `admin`.
3. **Сразу сменить пароль** — приложение само покажет экран «Смените пароль»
   и не пустит дальше, пока пароль не сменён. Учётка admin создаётся
   автоматически, если в базе нет ни одного администратора.
   Требование к любому новому паролю: **не короче 8 символов, обязательно
   буквы и цифры, не совпадает с логином** — слабый пароль сервер не примет.
   То же требование смены действует для учётных записей, созданных
   администратором, и после сброса пароля администратором.
   Защита от подбора: после 5 неверных попыток вход по логину блокируется
   на 30 секунд.
4. Настроить резервные копии (раздел 6) — рекомендуется включить автобэкап.

## 3. Роли и регистрация

| Роль | Что может |
|---|---|
| **Администратор** | всё: пользователи, книги, бэкапы, журнал, логи |
| **Старший** (power) | одобрение пользователей, книги, задания, журнал |
| **Учитель** | книги и задания своим классам, панель класса, заметки, квизы, одобрение учеников своих классов |
| **Ученик** | чтение назначенных/общих книг, синхронизация своего прогресса |

Порядок подключения ученика:
1. На устройстве: настройки → сервер → адрес сервера (или автопоиск в сети).
2. «Регистрация»: имя, класс, логин, пароль (например логин `student12`;
   пароль — не короче 8 символов, обязательно буквы и цифры).
3. Учитель или администратор **одобряет** заявку у себя в панели — до этого
   ученик в статусе «ожидает».
4. После одобрения ученику доступны книги его класса, прогресс и словарик
   синхронизируются между его устройствами.

## 4. Книги: загрузка и доступ (учитель/админ)

- Загрузка: кнопка загрузки книги в веб-интерфейсе сервера (EPUB, FB2, PDF,
  MOBI, AZW3, CBZ; до 512 МБ) — или файлом в папку `library`.
- У каждой книги — теги: **классы, предметы, категории** и флаг «доступна
  всем». Новая книга по умолчанию приватна: видна тем, кому назначены её
  классы/предметы, её владельцу и админам.
- Ученик видит только «свои» книги; скачивание чужих по прямой ссылке
  закрыто.

## 5. Инструменты учителя

- **Задания**: назначить книгу классу с дедлайном; отчёт — кто начал, кто
  дочитал, доля прочитанного.
- **Панель класса**: сводный прогресс всех учеников по книгам, выгрузка CSV.
- **Заметки классу**: выделить фрагмент в книге и опубликовать заметку —
  ученики класса увидят её в тексте (голубая подсветка).
- **Квизы**: свои вопросы по книге, проверка на сервере, результаты по
  ученикам.

## 6. Резервные копии (администратор)

Раздел админки **«Резервные копии»**.

- **Автобэкап**: включить и настроить — ежедневно в заданное время или каждые
  N часов; сколько копий хранить (старые удаляются сами); папка на сервере;
  включать ли книги (полный zip) или только базу (.db). Применяется сразу,
  без перезапуска.
- **Сделать копию сейчас** — по кнопке, в ту же папку.
- **Скачать на свой компьютер**: базу данных (.db — аккаунты, прогресс,
  задания, квизы) или полный архив с книгами (.zip).
- **Восстановление**: выбрать файл копии `.db` → подтвердить. Сервер сам
  сохранит страховочную копию текущей базы (`pre-restore-*.db`). После
  восстановления **перезапустить сервер** (закрыть окно и запустить снова).
- Перенос на новый компьютер: распаковать полный архив — `chitalka.db` и
  папку `library` положить рядом с `chitalka-server.exe`, запустить.

Рекомендация: автобэкап «ежедневно», хранить 7 копий; раз в четверть
скачивать полный архив на отдельный носитель.

## 7. Логи сервера (администратор)

Раздел админки **«Логи сервера»** — уровень подробности того, что сервер
пишет в своё окно/журнал:

- `error` — только сбои; `warn` — + предупреждения;
- `info` — **по умолчанию**: старт, бэкапы, новые книги;
- `debug` — + каждый запрос, входы пользователей (для разбора «у ученика не
  работает»);
- `verbose` — максимум деталей (включать на время диагностики, пишет много).

Выбор применяется мгновенно и сохраняется после перезапуска.

## 8. Обновления приложения

Если на сервере выложено обновление (папка `_updates` с `manifest.json` и
файлами), устройства показывают вкладку «Доступно обновление» — ученик
скачивает APK/установщик прямо с сервера, без интернета.

## 9. Частые вопросы

- **«Сервер недоступен»** — проверить: сервер запущен; устройство в той же
  Wi-Fi-сети; адрес и порт введены верно (порт из окна сервера, обычно 9700);
  брандмауэр не блокирует.
- **Забыт пароль администратора** — запустить сервер с переменными окружения
  `CHITALKA_ADMIN_LOGIN`/`CHITALKA_ADMIN_PASSWORD`: если активных админов нет,
  будет создан новый. Пароль ученика/учителя сбрасывает админ в панели
  пользователей.
- **Книга не появилась в каталоге** — подождать 15 секунд (автоскан) или
  проверить формат файла; у книги могут быть не заданы классы (тогда ученики
  её не видят).
- **Читает без сервера?** — да: приложение офлайн-первое, книги с устройства
  открываются всегда; сервер нужен для общей библиотеки, синхронизации и
  инструментов учителя.
